CompareCraft for Windows (Portable)

Extract this ZIP and run comparecraft.exe.

ccomp.exe is the console version. Use it from a command prompt, batch files
and version control tools: scripts (ccomp @script.txt) and quick compares
(ccomp -qc a b) print to the console, and comparisons wait until the window
is closed.

comparecraft-backend.exe is a windowless helper used by the CompareCraft
extension for Visual Studio Code. It only runs when the extension starts it;
you never need to open it yourself. Keep it next to comparecraft.exe.

Microsoft Edge WebView2 Runtime is required to run CompareCraft. This portable
ZIP does not install the runtime. If it is not already installed on your PC,
install it before launching CompareCraft.

Download the runtime from Microsoft's official page:
https://developer.microsoft.com/en-us/microsoft-edge/webview2/

On that page, download the Evergreen Standalone Installer for x64. Run the
downloaded installer and follow its prompts. After installation completes,
launch comparecraft.exe.
