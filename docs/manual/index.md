# CompareCraft User Manual

CompareCraft compares, merges and synchronizes files and folders. It shows exactly what changed between two versions of a document, a data file, a binary file, a picture or a whole folder tree, and it lets you copy changes from one side to the other, edit files in place and bring folders into sync.

CompareCraft runs on Linux, Windows and macOS.

![A Text Compare session showing two versions of a file side by side](images/text-compare.jpg)

## Comparison types

| Type | What it does |
| --- | --- |
| [Folder Compare](folder-compare.md) | Compare two folder trees and copy, move, delete, rename or touch items. |
| [Folder Sync](folder-sync.md) | Update or mirror one folder into another, with a preview of every action. |
| [Text Compare](text-compare.md) | Line-by-line text comparison with intraline highlights and editing. |
| [Text Merge](text-merge.md) | Three-way merge of left and right changes against a common base. |
| [Table Compare](table-compare.md) | Cell-by-cell comparison of CSV and TSV data with key columns. |
| [Hex Compare](hex-compare.md) | Byte-level comparison of binary files. |
| [Picture Compare](picture-compare.md) | Pixel comparison of images with tolerance, range and blend modes. |

CompareCraft also includes a plain text editor and a patch viewer, described in [Editing Files and Viewing Patches](editing-and-patches.md).
