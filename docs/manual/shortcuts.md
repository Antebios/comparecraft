# Keyboard Shortcuts

This page lists the default keyboard shortcuts of CompareCraft, grouped by view. Shortcuts only work in the view they belong to. For example, `Ctrl+R` copies to the right in Folder Compare and Text Compare, but takes the right side in Text Merge.

!!! tip "See the shortcuts of the current view"
    Press `Shift+F1` (**Help > Keyboard Shortcuts**) to see every shortcut available in the view you are working in. The menus also show each command's shortcut next to its name.

On macOS, `Ctrl` in this list means the Command key (⌘), and the menus show shortcuts with the macOS symbols.

You can change any shortcut on the [Toolbars, Shortcuts page of the Options](options.md#toolbars-shortcuts).

## All views

| Command | Shortcut |
| --- | --- |
| Session > Home | `Alt+Home` |
| Session > New Tab | `Ctrl+T` |
| Session > Select Next Tab | `Ctrl+Tab` |
| Session > Select Previous Tab | `Shift+Ctrl+Tab` |
| Session > Close Tab | `Ctrl+W` |
| Session > Exit | `Ctrl+Q` |
| Tools > Options… (macOS only) | `Ctrl+,` |
| Help > CompareCraft Help | `F1` |
| Help > Keyboard Shortcuts | `Shift+F1` |
| Open the menu bar | `F10` |
| Open the context menu for the selection | `Shift+F10` or the Menu key |

## Help window

| Action | Shortcut |
| --- | --- |
| Search the help | `Ctrl+F` |
| Move through the search results | `Up` / `Down` |
| Open the selected search result | `Enter` |
| Go back / forward | `Alt+Left` / `Alt+Right` |
| Clear the search, or close the help when the search is empty | `Esc` |
